User Roles

Understanding Permissions and Access

👁️ Role 1: Public Viewer
View-only access to public case information
Permissions:
✓ View public cases
✓ View evidence summaries
✗ Cannot upload evidence
✗ Cannot create cases

Best For: Media, public interest, general viewers

🔍 Role 2: Investigator
Full case and evidence management
Permissions:
✓ Create new cases
✓ Upload evidence
✓ Manage investigations
✓ Add case notes
✗ Cannot analyze evidence

Best For: Police officers, detectives, crime investigators

🔬 Role 3: Forensic Analyst
Technical analysis and forensic examination
Permissions:
✓ Analyze evidence
✓ Extract metadata
✓ Verify file hashes
✓ Generate analysis reports

Best For: Forensic experts, lab technicians

⚖️ Role 4: Legal Professional
Legal review and court preparation
Permissions:
✓ Review cases
✓ Approve for court
✓ Add legal notes
✓ Generate court documents

Best For: Lawyers, prosecutors, legal advisors

🏛️ Role 5: Court Official
Judicial proceedings and evidence admission
Permissions:
✓ Manage judicial proceedings
✓ Approve evidence admission
✓ Issue rulings
✓ View case status

Best For: Judges, court administrators

📦 Role 6: Evidence Manager
Chain of custody and storage management
Permissions:
✓ Manage evidence storage
✓ Track chain of custody
✓ Update evidence status
✓ Generate custody reports

Best For: Evidence custodians, storage managers

📊 Role 7: Auditor
Compliance and audit access
Permissions:
✓ View all activities
✓ Generate audit reports
✓ Verify compliance
✓ Track all changes

Best For: Compliance officers, auditors

👑 Role 8: Administrator
Complete system control and management
Permissions:
✓ Full system access
✓ Manage all users
✓ Create/delete users
✓ Manage system settings
✓ View all data

Best For: System administrators, IT managers
