# Original offline packet examples

Generated by scripts/generate-network-samples.py. Four synthetic Ethernet/IPv4 packets: DNS query, TCP SYN/SYNACK and HTTP request. Documentation-address ranges and demo.example are used. No packets were captured from a real person or sent to any host. Classic PCAP and PCAPNG encode the same packets. Checksums: IPv4/TCP computed, IPv4 UDP zero checksum is intentional.
