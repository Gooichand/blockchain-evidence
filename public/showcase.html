Capabilities

Four guarantees, one pipeline

Each layer below is independently auditable. A compromised database still cannot rewrite what the ledger has already recorded.

⛓

On-chain anchoring

EvidenceStorage.sol stores the SHA-256 digest of each artefact on Polygon Amoy through ethers v6, so the record cannot be edited or removed by any operator.

working
◈

Decentralised storage

Files are pinned to IPFS via Pinata at upload time — content-addressed, deduplicated, and independent of the application server.

working
⚖

Authorisation

Eight roles with server-enforced page guards and role-scoped routers. Ownership and legal-hold state are evaluated per request, never trusted from the client.

working
✓

Public verification

Anyone can look up an evidence ID and get a verdict. It currently resolves against the database only — the ledger cross-check is not wired in yet.

partial
◉

Forensic workbench

A twelve-tool interface in the analyst dashboard. The SHA-256 engine is real; the other eleven report "under development" rather than returning fabricated results.

1 of 12 engines
⇄

Live audit stream

Socket.IO maintains per-wallet notification rooms on the server. The browser client is not implemented, so notifications are polled rather than pushed.

server only
