EVID-DGC

Desktop Access Required

EVID-DGC is designed for desktop use only. Mobile and tablet devices are not supported for security and functionality reasons.

Requirements

  • Desktop or laptop computer
  • Minimum 1024px screen width
  • MetaMask browser extension (for blockchain features)
  • Modern browser (Chrome, Firefox, Edge, Brave)

If you believe this is an error, try force desktop mode
